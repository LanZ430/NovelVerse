# Novel Metadata Reference

## Character Schema
Characters can be stored as dict (name as key) or list of objects with `name` field.

## Plot Structure
Each plot entry may have: `chapter`, `summary`, `events`, `key_anchors`.

## Book Skill Package
Per-book metadata in `data/books/{document_id}/`:
- characters.json, plots.json, settings.json, world_metadata.json
